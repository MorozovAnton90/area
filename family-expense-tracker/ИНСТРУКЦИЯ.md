# Семейный трекер расходов — пошаговая инструкция

## Что нужно сделать (общий план)

1. Создать Telegram-бота через BotFather
2. Создать Google Таблицу
3. Создать Apps Script проект и вставить код
4. Настроить токен бота и ID таблицы в коде
5. Опубликовать скрипт как веб-приложение
6. Подключить webhook
7. Протестировать

---

## Шаг 1. Создание Telegram-бота

1. Откройте Telegram, найдите бота **@BotFather**
2. Напишите ему `/newbot`
3. BotFather попросит имя бота — напишите любое, например: `Семейные расходы`
4. Затем попросит username (должен заканчиваться на `bot`), например: `myfamily_expenses_bot`
5. BotFather ответит примерно так:
   ```
   Done! Congratulations on your new bot.
   Use this token to access the HTTP API:
   1234567890:ABCdefGHIjklMNOpqrSTUvwxYZ
   ```
6. **Скопируйте токен** — он понадобится в шаге 4

---

## Шаг 2. Узнать свои Chat ID (для ограничения доступа)

Это важно — чтобы бот реагировал только на ваши сообщения.

1. Найдите в Telegram бота **@userinfobot**
2. Напишите ему `/start`
3. Он ответит вашим ID, например: `Id: 123456789`
4. **Запишите свой ID** и ID второго члена семьи (пусть он тоже напишет @userinfobot)

---

## Шаг 3. Создание Google Таблицы

1. Перейдите на **sheets.google.com**
2. Нажмите **+** (Создать таблицу)
3. Дайте ей название, например: `Семейные расходы 2026`
4. Посмотрите на адрес страницы — он выглядит так:
   ```
   https://docs.google.com/spreadsheets/d/1abc...XYZ/edit#gid=0
   ```
5. **Скопируйте ID таблицы** — это часть между `/d/` и `/edit`:
   ```
   1abc...XYZ
   ```
6. Лист с данными создастся автоматически при первом запуске бота.
   Или создайте его вручную: нажмите **+** внизу, назовите лист **Расходы**,
   добавьте в первую строку заголовки:
   ```
   ID | Дата | Сумма | Категория | Комментарий | Автор | Исходное сообщение | Message ID Telegram | Chat ID
   ```

## Шаг 4. Создание Apps Script проекта

### 4.1 Открыть редактор скриптов

В Google Таблице нажмите в верхнем меню:
**Расширения → Apps Script**

Откроется редактор кода. По умолчанию там уже есть файл `Code.gs`.

### 4.2 Создать файлы

В редакторе слева нажмите **+** рядом с "Файлы" и создайте файлы:
- `Code.gs` (уже есть)
- `Parser.gs`
- `Sheets.gs`
- `Commands.gs`

### 4.3 Вставить код

Для каждого файла: кликните на него слева, выделите весь код (Ctrl+A), удалите и вставьте код из соответствующего файла этого проекта.

**Порядок:**
1. Откройте файл `Code.gs` в проекте, скопируйте всё содержимое → вставьте в редакторе в `Code.gs`
2. То же самое для `Parser.gs`, `Sheets.gs`, `Commands.gs`

### 4.4 Вставить токен и ID таблицы

В файле `Code.gs` найдите строки вверху:

```javascript
var BOT_TOKEN = "";        // ← СЮДА вставьте токен от BotFather
var ALLOWED_CHAT_IDS = []; // ← СЮДА вставьте ваши Chat ID
```

В файле `Sheets.gs` найдите:

```javascript
var SPREADSHEET_ID = ""; // ← СЮДА вставьте ID таблицы
```

**Пример заполнения:**

```javascript
// В Code.gs:
var BOT_TOKEN = "1234567890:ABCdefGHIjklMNOpqrSTUvwxYZ";
var ALLOWED_CHAT_IDS = [123456789, 987654321];

// В Sheets.gs:
var SPREADSHEET_ID = "1abc...XYZ";
```

## Шаг 5. Публикация скрипта

1. В редакторе Apps Script нажмите кнопку **Развернуть** (правый верхний угол) → **Новое развёртывание**
2. Нажмите иконку шестерёнки рядом с "Тип" → выберите **Веб-приложение**
3. Настройки:
   - **Описание**: `Семейный трекер расходов`
   - **Выполнять как**: `Я` (ваш аккаунт)
   - **Кто имеет доступ**: **Все** (это важно — Telegram должен достучаться!)
4. Нажмите **Развернуть**
5. Google попросит разрешения — нажмите **Авторизовать доступ**, выберите свой аккаунт, нажмите **Дополнительно** → **Перейти к [название проекта]** → **Разрешить**
6. После развёртывания скопируйте **URL веб-приложения** — он выглядит так:
   ```
   https://script.google.com/macros/s/AKfycby.../exec
   ```
   > ⚠️ Важно: URL должен заканчиваться на `/exec`, не `/dev`!

## Шаг 6. Подключение webhook

1. В редакторе Apps Script выберите файл `Code.gs`
2. В выпадающем списке функций (посередине вверху, где написано `myFunction`) выберите **setWebhook**
3. Нажмите **Выполнить** (кнопка ▶)
4. В логах внизу должно появиться что-то вроде:
   ```json
   {"ok":true,"result":true,"description":"Webhook was set"}
   ```
5. Если хотите проверить — выберите функцию **getWebhookInfo** и нажмите **Выполнить**.
   В логах увидите URL webhook и дату последнего обращения.

## Шаг 7. Тестирование

1. Откройте Telegram и найдите вашего бота (по username, который дал BotFather)
2. Напишите `/start` — бот должен ответить справкой
3. Напишите `1840 пятерочка` — бот должен записать и ответить подтверждением
4. Напишите `950 книга` — бот не определит категорию и покажет кнопки
5. Нажмите на кнопку с категорией — бот обновит сообщение
6. Откройте Google Таблицу — в листе "Расходы" должна появиться строка с данными

---

## Обновление кода

Если вы изменили код и хотите применить изменения:

1. В редакторе нажмите **Развернуть** → **Управление развёртываниями**
2. Нажмите иконку карандаша (редактировать)
3. В поле "Версия" выберите **Новая версия**
4. Нажмите **Развернуть**

> ⚠️ URL не изменится — webhook переустанавливать не нужно.

## Возможные проблемы

### Бот не отвечает
- Проверьте, что токен вставлен правильно (без пробелов)
- Проверьте, что скрипт опубликован с доступом "Все"
- Запустите `getWebhookInfo` и проверьте поле `url`

### "Нет доступа"
- Ваш Chat ID не добавлен в `ALLOWED_CHAT_IDS`
- Оставьте список пустым `[]` на время тестирования, потом добавьте

### Данные не записываются в таблицу
- Проверьте `SPREADSHEET_ID` в `Sheets.gs`
- Убедитесь, что скрипт запускается от имени аккаунта с доступом к таблице

### Категории не определяются
- Попробуйте написать явно: `еда 500 обед`
- Или просто `500 обед` — бот покажет кнопки выбора категории

## Структура данных в таблице

| Столбец | Содержимое |
|---------|------------|
| A (ID) | Уникальный идентификатор записи |
| B (Дата) | Дата и время записи |
| C (Сумма) | Числовая сумма |
| D (Категория) | Определённая категория |
| E (Комментарий) | Текст без суммы |
| F (Автор) | Имя из Telegram |
| G (Исходное сообщение) | Оригинальный текст |
| H (Message ID Telegram) | Для внутреннего использования |
| I (Chat ID) | Для внутреннего использования |

## Команды бота

| Команда | Что делает |
|---------|------------|
| `/start` или `/help` | Справка |
| `/today` | Все расходы за сегодня |
| `/month` | Расходы месяца по категориям с процентами |
| `/top` | Топ-10 самых крупных трат месяца |
| `/uncategorized` | Траты с категорией "Непонятное" |
