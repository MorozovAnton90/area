# CLAUDE.md

## Оркестрация Workflow

### 1. Режим планирования по умолчанию
- Всегда сначала делай план (минимум 3 шага или архитектура)
- Если план некорректный — остановись и перепланируй
- Используй план для проверки, а не формальности
- Продумывай детали заранее, избегай неоднозначности

### 2. Стратегия субагентов
- Декомпозируй сложные задачи
- Используй параллельное мышление
- Одна задача = один фокус
- Разделяй ответственность между подзадачами

### 3. Цикл самообучения
- После каждой итерации обновляй lessons
- Фиксируй ошибки и правила, чтобы не повторять их
- Итерации до снижения количества ошибок
- Повторяй ключевые уроки в начале новой сессии

### 4. Верификация
- Ничего не считать готовым без доказательства
- Проверяй гипотезы
- Запускай тесты
- Демонстрируй, что решение работает

### 5. Элегантность решений
- Ищи более простые решения
- Избегай усложнения
- Не оптимизируй преждевременно
- Думай о читаемости и понятности

### 6. Починка багов
- Сначала воспроизвести баг
- Проверить логи
- Написать тест
- Не делать предположений без проверки

---

## Управление задачами

1. Пиши план в tasks/todo.md
2. Проверяй план перед началом
3. Отслеживай прогресс
4. Фиксируй изменения
5. Веди документацию
6. Обновляй lessons после работы

---

## Базовые принципы

- Простота в приоритете
- Решай корневые причины, а не симптомы
- Минимальные изменения
- Без костылей
- Подход уровня senior
